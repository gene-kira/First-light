⚙️ What it does for you
Runs deep learning experiments automatically using TensorFlow and Optuna.

Optimizes hyperparameters (learning rate, etc.) through Optuna trials.

Trains Conv3D temporal CNNs on demo or real datasets.

Applies pruning and quantization to reduce model size and improve efficiency.

Exports models in both .keras and .tflite formats for deployment.

Monitors GPU memory and logs all activity.

Provides a live GUI built with PyQt5 — showing progress, logs, and status.

Operates as a daemon: when one training cycle finishes, it instantly starts the next.

🧠 Core architecture
Subsystem	Purpose
Optuna Engine	Searches for best hyperparameters automatically.
TensorFlow Trainer	Builds and trains Conv3D CNNs.
Pruning Module	Reduces model complexity (best‑effort fallback).
Quantization Exporter	Converts models to lightweight TFLite.
GPU Monitor	Tracks VRAM usage and prevents overload.
GUI Layer	Displays logs, controls, and allows safe stop/restart.
Continuous Loop	Keeps training indefinitely — no downtime.


✅ Pros
Fully autonomous — no manual restarts or supervision needed.

Crash‑resistant — exceptions are caught and logged, not fatal.

Cross‑platform GUI — works on Windows, Linux, macOS.

Modular design — easy to plug in new models or datasets.

Best‑effort pruning and TFLite conversion — never halts on incompatibility.

Real‑time GPU monitoring — prevents resource exhaustion.

Continuous operation — ideal for long‑term experiments or production training.

Readable logs and metrics — classification reports, confusion matrices, ROC/PR curves.

⚠️ Cons / Trade‑offs
High resource usage — continuous training can consume GPU and disk space.

Limited dataset realism — demo data is random unless replaced with real input.

No distributed training — single‑machine only (no multi‑GPU or cluster support).

GUI dependency — PyQt5 adds overhead; headless mode would need adaptation.

Basic model architecture — Conv3D CNN is simple; not optimized for complex tasks.

No built‑in alerting — failures are logged but not externally notified.

Optuna trials are minimal (3) — good for demo, but not exhaustive optimization.

🧩 In short
This program is your autonomous deep‑learning lab assistant.
It continuously trains, optimizes, prunes, and exports models — all while showing live progress in a GUI. It’s robust, self‑healing, and ideal for unattended operation or experimental environments where you want to keep improving models around the clock.
